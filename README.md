# Minerva Lab

https://minervalab.jp のソースです。

## 公開中のアプリ
- [持ち物リスト](https://list.minervalab.jp/) — 外出前の持ち物チェック（別リポジトリ `list`）
- [送迎お小遣いメモ](https://minervalab.jp/taxi/) — 送迎のお小遣いをワンタップ記録（2人で共有・Supabase）
- [Habita Daily](https://minervalab.jp/habita/) — 英単語10語とランニング3kmを毎日ワンタップ記録する習慣トラッカー
- [DailyEnglish](https://minervalab.jp/english/) — 日本語の日記を自分で英語にして、AIの自然な英語と見比べる英語日記（データは端末内）
- [命式計算](https://minervalab.jp/meishiki/) — 出生データから四柱推命の命式・詳細診断・大運・2人の相性を出す実務用ツール（データは端末内）
- [旅の足跡](https://minervalab.jp/tabinoashi/) — 世界249の国・地域と日本47都道府県の訪問状況を地図で記録する旅行記録アプリ（データは端末内、オフライン対応）
- [きょうあした予定帳](https://minervalab.jp/schedule/) — 今日・明日の予定をすぐ書けるタイムライン＋4マス優先度の予定帳（データは端末内）
- [Tabiji](https://minervalab.jp/tabiji/) — 旅の経路を3D地球儀の上で乗り物が走るアニメにして動画保存できる旅路アニメマップ（データは端末内）
